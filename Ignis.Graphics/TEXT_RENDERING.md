# Using FontStashSharp with Silk.NET

This guide explains how to render high-performance text in a Silk.NET application using FontStashSharp. FontStashSharp is platform-agnostic, meaning it does not know about OpenGL or Silk.NET by default. To make them work together, you must implement specific interfaces that handle texture management and geometry rendering.

## 2. Implementing the Backend

FontStashSharp requires two main components to communicate with the GPU:
1.  **Texture Manager**: Handles creating and updating font texture atlases.
2.  **Renderer**: Handles drawing the actual quads (letters) generated by the font system.

### A. Texture Management

First, you need a helper class to wrap raw OpenGL texture calls.

**`Texture.cs`** (Simplified Wrapper)
```csharp
using Silk.NET.OpenGL;
using System;
using System.Drawing;

public unsafe class Texture : IDisposable
{
    private readonly uint _handle;
    public int Width { get; }
    public int Height { get; }

    public Texture(int width, int height)
    {
        Width = width;
        Height = height;
        _handle = Env.Gl.GenTexture();
        
        Bind();
        // Allocate memory
        Env.Gl.TexImage2D(TextureTarget.Texture2D, 0, InternalFormat.Rgba8, (uint)width, (uint)height, 0, PixelFormat.Rgba, PixelType.UnsignedByte, null);
        
        // Set parameters (Linear filtering is usually best for fonts)
        Env.Gl.TexParameter(TextureTarget.Texture2D, TextureParameterName.TextureMinFilter, (int)GLEnum.Linear);
        Env.Gl.TexParameter(TextureTarget.Texture2D, TextureParameterName.TextureMagFilter, (int)GLEnum.Linear);
    }

    public void Bind() => Env.Gl.BindTexture(TextureTarget.Texture2D, _handle);

    public void SetData(Rectangle bounds, byte[] data)
    {
        Bind();
        fixed (byte* ptr = data)
        {
            Env.Gl.TexSubImage2D(TextureTarget.Texture2D, 0, bounds.Left, bounds.Top, (uint)bounds.Width, (uint)bounds.Height, PixelFormat.Rgba, PixelType.UnsignedByte, ptr);
        }
    }

    public void Dispose() => Env.Gl.DeleteTexture(_handle);
}
```

Next, implement `ITexture2DManager` to bridge FontStashSharp with your Texture class.

**`Texture2DManager.cs`**
```csharp
using FontStashSharp.Interfaces;
using System.Drawing;

public class Texture2DManager : ITexture2DManager
{
    public object CreateTexture(int width, int height) => new Texture(width, height);

    public Point GetTextureSize(object texture)
    {
        var t = (Texture)texture;
        return new Point(t.Width, t.Height);
    }

    public void SetTextureData(object texture, Rectangle bounds, byte[] data)
    {
        var t = (Texture)texture;
        t.SetData(bounds, data);
    }
}
```

### B. The Renderer

You need to implement `IFontStashRenderer2`. This class collects vertices produced by the font system and submits them to OpenGL using a Shader, VBO (Vertex Buffer Object), and EBO (Element Buffer Object).

**Shaders**
You need basic shaders to render textured colored vertices.

*Vertex Shader (`shader.vert`)*
```glsl
attribute vec3 a_position;
attribute vec4 a_color;
attribute vec2 a_texCoords0;
uniform mat4 MatrixTransform;
varying vec4 v_color;
varying vec2 v_texCoords;

void main() {
    v_color = a_color;
    v_texCoords = a_texCoords0;
    gl_Position = MatrixTransform * vec4(a_position, 1.0);
}
```

*Fragment Shader (`shader.frag`)*
```glsl
uniform sampler2D TextureSampler;
varying vec4 v_color;
varying vec2 v_texCoords;

void main() {
    gl_FragColor = v_color * texture2D(TextureSampler, v_texCoords);
}
```

**`Renderer.cs`** (Implementation)
*Note: This relies on standard OpenGL boilerplate (BufferObject, VertexArrayObject, Shader) found in the samples provided.*

```csharp
using FontStashSharp.Interfaces;
using Silk.NET.OpenGL;
using System.Numerics;

public class Renderer : IFontStashRenderer2, IDisposable
{
    private readonly Texture2DManager _textureManager;
    private readonly Shader _shader;
    private readonly BufferObject<VertexPositionColorTexture> _vertexBuffer;
    private readonly VertexArrayObject _vao;
    
    // Batching logic
    private readonly VertexPositionColorTexture[] _vertexData = new VertexPositionColorTexture[8192];
    private int _vertexIndex = 0;
    private object _lastTexture;

    public ITexture2DManager TextureManager => _textureManager;

    public Renderer()
    {
        _textureManager = new Texture2DManager();
        _shader = new Shader("shader.vert", "shader.frag");
        
        // Setup VAO/VBO layout (Position: 0, Color: 1, TexCoord: 2)
        // See provided VertexArrayObject.cs for implementation details
        _vao = new VertexArrayObject(sizeof(VertexPositionColorTexture));
        // ... (VertexAttribPointer setup) ...
    }

    public void Begin(Matrix4x4 transform)
    {
        Env.Gl.Enable(EnableCap.Blend);
        Env.Gl.BlendFunc(BlendingFactor.One, BlendingFactor.OneMinusSrcAlpha);
        _shader.Use();
        _shader.SetUniform("MatrixTransform", transform);
        _vao.Bind();
    }

    public void DrawQuad(object texture, ref VertexPositionColorTexture topLeft, ref VertexPositionColorTexture topRight, ref VertexPositionColorTexture bottomLeft, ref VertexPositionColorTexture bottomRight)
    {
        if (_lastTexture != texture) FlushBuffer();
        
        // Add vertices to array
        _vertexData[_vertexIndex++] = topLeft;
        _vertexData[_vertexIndex++] = topRight;
        _vertexData[_vertexIndex++] = bottomLeft;
        _vertexData[_vertexIndex++] = bottomRight;
        
        _lastTexture = texture;
    }

    public void End() => FlushBuffer();

    private void FlushBuffer()
    {
        if (_vertexIndex == 0 || _lastTexture == null) return;

        // Upload data to GPU
        _vertexBuffer.SetData(_vertexData, 0, _vertexIndex);
        
        // Bind Texture
        ((Texture)_lastTexture).Bind();
        
        // Draw
        Env.Gl.DrawElements(PrimitiveType.Triangles, (uint)(_vertexIndex * 1.5), DrawElementsType.UnsignedShort, null);
        
        _vertexIndex = 0;
    }
    
    public void Dispose() { /* Dispose buffers and shaders */ }
}
```

## 3. Basic Usage

Here is how to wire everything up in your `Program.cs`.

```csharp
using Silk.NET.Windowing;
using Silk.NET.OpenGL;
using FontStashSharp;
using System.IO;
using System.Numerics;

static class Program
{
    private static IWindow window;
    private static GL Gl;
    private static Renderer renderer;
    private static FontSystem fontSystem;

    static void Main(string[] args)
    {
        var options = WindowOptions.Default;
        window = Window.Create(options);
        window.Load += OnLoad;
        window.Render += OnRender;
        window.Closing += OnClose;
        window.Run();
    }

    private static void OnLoad()
    {
        // 1. Initialize OpenGL
        Gl = GL.GetApi(window);
        Env.Gl = Gl; // Store global reference for helpers

        // 2. Create Renderer
        renderer = new Renderer();

        // 3. Create FontSystem
        var settings = new FontSystemSettings
        {
            FontResolutionFactor = 2, // Retains quality when scaling up
            KernelWidth = 2,
            KernelHeight = 2
        };
        fontSystem = new FontSystem(settings);

        // 4. Load a Font
        byte[] fontData = File.ReadAllBytes("Fonts/DroidSans.ttf");
        fontSystem.AddFont(fontData);
    }

    private static void OnRender(double delta)
    {
        Gl.Clear((uint)ClearBufferMask.ColorBufferBit);

        // Calculate Orthographic Projection (Pixel Perfect)
        var transform = Matrix4x4.CreateOrthographicOffCenter(
            0, window.Size.X, 
            window.Size.Y, 0, 
            0, -1);

        renderer.Begin(transform);

        // Get the specific font size instance
        var font = fontSystem.GetFont(30);

        // Draw Text
        font.DrawText(renderer, "Hello Silk.NET!", new Vector2(100, 100), FSColor.White);

        renderer.End();
    }

    private static void OnClose()
    {
        renderer.Dispose();
    }
}
```

## 4. Advanced Features

### Rich Text (Colors and Formatting)

To support formatted text (e.g., "Hello /c[red]World"), use `RichTextLayout`.

```csharp
// Setup
var richText = new RichTextLayout
{
    Font = fontSystem.GetFont(32),
    Text = "This is /c[red]colored /c[#00FF00]text.",
    Width = 500 // Wrap width
};

// Render Loop
richText.Draw(renderer, new Vector2(50, 50), FSColor.White);
```

### Complex Scripts (HarfBuzz)

If you need to render Arabic, Hebrew, Hindi, or use advanced ligatures, you must enable HarfBuzz.

1.  Add the `FontStashSharp.TextShapers.HarfBuzz` NuGet package.
2.  Configure the settings during initialization:

```csharp
var settings = new FontSystemSettings
{
    TextShaper = new HarfBuzzTextShaper() // Enables complex shaping
};
fontSystem = new FontSystem(settings);
fontSystem.AddFont(File.ReadAllBytes("NotoSansArabic.ttf"));
```

### TrippyGL Integration

If you prefer using the high-level **TrippyGL** library over raw OpenGL, the integration is simpler because TrippyGL handles textures and batching for you.

1.  Implement `ITexture2DManager` wrapping `TrippyGL.Texture2D`.
2.  Implement `IFontStashRenderer` (Simpler interface than `IFontStashRenderer2`) using `TrippyGL.TextureBatcher`.

*See `samples/FontStashSharp.Samples.Silk.NET.TrippyGL` for the full implementation.*

## 5. Directory Structure Recap

To keep your project organized, follow the structure found in the samples:

*   **Platform/**: Contains your `Renderer.cs`, `Texture2DManager.cs`, and OpenGL wrapper classes.
*   **Assets/Fonts/**: Store your `.ttf` files here.
*   **Shaders/**: Store your `.vert` and `.frag` files.
